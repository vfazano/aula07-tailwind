# Aula 07: projeto Tailwind CSS

Aplicação React/Vite com Tailwind CSS v4 e plugin oficial do Vite.

## Executar

```bash
npm install
npm run dev
```

A relação das classes distintas usadas e suas funções está em `CLASSES.md`. O projeto precisa ser enviado a um repositório GitHub e os prints reais devem ser adicionados ao documento de entrega.
